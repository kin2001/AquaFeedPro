# ART-121 History and notifications implementation plan

**Goal:** Apply the approved neutral native presentation to history, filters, run details and notifications without changing their data or action contracts.

**Architecture:** Reuse ART-118's semantic theme, grouped cards, rows, sheets and native date/status controls. Keep existing loaders, scope guards, pagination, notification controller and handlers intact.

**Tech stack:** Expo 58, React Native 0.88, TypeScript, Expo Router, existing Lucide icons.

**Spec:** [ART-121](https://linear.app/artkin/issue/ART-121), [ART-117 reference](../../design/ui4-native-foundation/README.md).

## Review focus and acceptance gates

- Unknown/partial/rejected outcomes retain distinct status labels/icons; requested doses never become measured totals.
- History rows remain keyed by sequence ID; no row entrances added, no scroll key/reset introduced by pagination.
- Date selection, retained filters and scope checks retain existing contracts.
- Notification actions keep the correct feeder/run IDs; unread is visible without relying on color.
- Long names, status text, units and values wrap; large-text layout stacks rather than clipping.
- Physical Android is disconnected at startup. Both themes, large text, reduced motion, keyboard/back, TalkBack and real app-open/remote-notification observation remain explicit owner test gates. No cloud delivery claim.
